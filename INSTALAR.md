# Cómo instalar GymQuest en tu Android

1. Entra a GitHub → pestaña **Actions** del repositorio → abre la ejecución más reciente en verde de **CI**.
2. Abajo, en **Artifacts**, descarga **gymquest-debug-apk** (es un .zip; descomprímelo y dentro está `app-debug.apk`).
3. Pasa el `.apk` a tu teléfono y ábrelo. Android pedirá permiso para "instalar apps de origen desconocido": acéptalo solo para este archivo.
4. Abre **GymQuest**, completa tus datos y concede los permisos cuando los pida (cámara para contar repeticiones, ubicación para el GPS).

## Qué esperar
- Es una versión de prueba (`debug`): ocupa más y va más lenta que la final. La versión optimizada se genera aparte.
- Todo lo que está en el teléfono funciona **sin internet**: contar repeticiones, jefes, GPS, comidas, agua, skincare, música.
- Los **mapas** se ven con internet; para usarlos sin conexión descarga tu zona en *Mapa → Mapas sin internet*.
- Las funciones con otras personas (amigos, gremios, ranking, mercado, chat) necesitan un servidor que aún no existe.

## Ayúdame a calibrar
La cámara y el GPS se afinan con uso real. Si una sentadilla no cuenta o cuenta de más, anota: ejercicio, dónde
pusiste el teléfono (de lado/de frente, distancia) y qué pasó. Con eso se ajustan los umbrales.
